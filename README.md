# St. Barths Massage by Tranquilitas

Static-first luxury destination site for Tranquilitas mobile massage in Saint Barthélemy.

## Cloudflare Pages
- Build command: leave blank
- Output directory: /
- Pages Functions are in `functions/api/booking-request.js`

## Required environment variables
- `RESEND_API_KEY` (secret)
- `BOOKING_FROM_EMAIL` = `Tranquilitas <bookings@bahamasmassages.com>`

## Canonical host
https://stbarthsmassage.com

## Source grounding
Pricing, service areas, existing imagery, service hours and trust references were taken from the existing private `PearsonLegacyVentures/stbarths` repository. New copy and page architecture were written separately to avoid cloning the existing website.
